# Slides — deck institucional EFFICAX

Oito tipos de slide em 1280 × 720 px (16:9). Nao havia deck anterior: estes modelos foram derivados dos fundamentos visuais do design system.

| Arquivo | Tipo |
|---|---|
| `01-title.html` | capa grafite |
| `02-section.html` | divisor de secao com numero gigante em verde-100 |
| `03-agenda.html` | agenda numerada, duas colunas |
| `04-stats.html` | quatro cifras em mono tabular |
| `05-services.html` | grade de cinco servicos + cartao de CTA |
| `06-table.html` | demonstrativo financeiro |
| `07-quote.html` | depoimento sobre grafite |
| `08-closing.html` | encerramento em verde da marca |

Regras: um fundo escuro ou verde por deck a cada 4–5 slides claros; texto nunca abaixo de 24px (legenda minima 15px em 1280px = 22px em tela cheia); logo sempre no canto inferior direito, numero de pagina em mono a esquerda.
