Icone Lucide. Herda a cor do texto, entao basta definir `color` no contentor.

```jsx
<Icon name="trending-up" size={20} />
<Icon name="file-text" size={16} color="var(--brand)" />
```

Set aprovado (substituicao documentada no readme): Lucide, stroke 2. Icones usados com mais frequencia: `trending-up`, `handshake`, `calculator`, `file-text`, `search-check`, `landmark`, `arrow-right`, `chevron-right`, `download`, `phone`, `mail`, `linkedin`. Nunca use emoji.
