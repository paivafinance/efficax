# UI kit — Site institucional EFFICAX

Recriacao de um site institucional completo para a EFFICAX, montado **apenas** com os componentes do design system (`window.EFFICAXDesignSystem_edde19`).

| Arquivo | Superficie |
|---|---|
| `index.html` | shell navegavel (header + rodape + troca de pagina) |
| `Chrome.jsx` | `SiteHeader`, `SiteFooter`, `Section`, `PhotoSlot` |
| `Home.jsx` | hero grafite, faixa de numeros, grade de servicos, metodo, depoimentos, CTA verde |
| `Services.jsx` | abas por frente de servico, entregaveis, tabela de impacto, painel lateral |
| `Cases.jsx` | lista de casos com filtro por servico |
| `Contact.jsx` | formulario com validacao simples e dialogo de confirmacao |

## Observacoes
- **Sem fotografia.** A marca nao forneceu imagens; todo espaco de imagem usa `PhotoSlot` (bloco cinza com legenda). Substituir por fotos reais antes de publicar.
- Conteudo e **exemplo plausivel** baseado no briefing (M&A, controladoria, funding, valuation, novos negocios). Numeros, casos e depoimentos sao ilustrativos e precisam de validacao.
- Nao existia site anterior nem Figma: este kit e uma **proposta de estrutura**, nao a recriacao de um produto existente.
